# Plugin WordPress para pastymas.es

Carpeta `pastymas-traducciones/`: plugin "Pastymas – Traducciones y ajustes de tienda" (v1.8).

- Traducciones al español de los widgets Carrito/Checkout de Elementor Pro, etiquetas del checkout, mini-cesta y textos del pie.
- Estilos de carrito, checkout, ficha de producto y versión móvil (`assets/*.css`).
- Buscador instantáneo de productos con índice local (`assets/pastymas-buscador.js`).
- Protección antispam del registro de clientes (`pastymas-antispam.php`).

Instalación: comprimir la carpeta `pastymas-traducciones` en un zip y subirlo en Plugins > Añadir nuevo > Subir plugin
("Reemplazar el actual con el subido" si ya está instalado).

```
cd tools/pastymas-web && zip -r pastymas-traducciones.zip pastymas-traducciones
```
